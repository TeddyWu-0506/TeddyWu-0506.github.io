闭环故事版Pain → Map → Build → Ship → Iterate → ↺
01Pain

业务痛点

达人数据散在飞瓜、MCN 与自建表格三处，人工筛号 30min/次，大促批量 KOC 完全撑不住。

3 套数据源 · 30min/次
02Map

梳理流程

先统一口径：五维标准化字段 + 四套场景权重。种草、品宣、拉新、大促，要的不是同一批人。

5 维字段 · 4 套权重
03Build

Vibecoding 做 MVP

多支路召回 + 场景权重重排，先用 @@index.size@@ 条脱敏样例把整条链路跑通，再接真实索引。

多支路召回
04Ship

上线团队使用

选号 @@match.time@@，中选率 30%→50%。每个候选附逐维解释——写得出来才改得动。

@@match.time@@
05Iterate

收集反馈迭代

人工修正回流进字段与权重，匹配率 @@match.pool@@；数据过期的候选自动降级为「需人工核实」。

匹配率 @@match.pool@@
